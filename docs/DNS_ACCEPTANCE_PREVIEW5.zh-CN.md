# preview.5 修复与验收记录

构建：1.9.11-dns-preview.5，Windows x64 自包含单 EXE。

## 本次错误的原因

用户提供的 2026-09-23 日志显示：22:33:35 在“连接远程 DNS”阶段启动失败，随后 TCP 接收报 995，UDP 和后续手动查询报 Winsock 10093（未初始化）；手动记录中的 TCP/UDP 53 监听列表均为空。之后通用提示错误地引导用户检查端口占用。

代码中的进程模式控制器在远程 DNS 就绪之前已创建。远程验证失败后，停止流程会调用尚未初始化的 Redirector 的 `aio_free`。现用原生组件的清理函数无条件调用 `WSACleanup`；未配对的调用会释放 .NET 使用的 Winsock 状态，导致当前及后续套接字失败。这解释了连续重试、恢复 DNS 后仍无法监听的现象。

修复：原生初始化/释放串行且配对；初始化未发生时停止无操作，重复停止不重复释放；正确声明原生 void 清理函数。DNS 绑定失败保留协议、地址、实际端口、原生错误码和内部异常，区分占用、拒绝访问和未初始化；部分绑定失败释放资源，运行时分离失败实例。远程 DNS 启动失败保留具体原因。

删除应用内手动验收菜单、测试窗口、监听/断线测试入口、自检报告、测试会话记录和调试统计。保留日常故障日志、DNS 策略设置及“停止并恢复系统 DNS”。不删除用户已有日志。

## 通过的验证

- 27 组回归：双栈 TCP/UDP 监听、五次未初始化停止、重复恢复和八次相同端口重绑定、四种端点占用后释放、已失败的接收任务清理、2000 个畸形查询、超时/远程备用/禁止本地回退、缓存失效、SOCKS 远程域名、DoH/DoT 错误证书拒绝、核心配置及实际 Xray DNS 路由、规则与配置持久化等。
- 真实系统失败路径：不可达节点在远程 DNS 阶段启动失败后，四种 loopback DNS 均能返回 SERVFAIL，网络接口未被错误释放；重复恢复成功。
- 真实节点：多次启动成功，A、AAAA、HTTPS 记录及 NXDOMAIN 在 IPv4/IPv6 的 UDP/TCP 下正常。
- 精确结束测试副本拥有的 Xray 核心后，DNS 停止提供成功应答，防护保留；重复停止后仍返回 SERVFAIL；重连成功。
- “停止并恢复系统 DNS”后再次启动成功。每次最终恢复后，FastLink/WLAN 的静态 DNS/DHCP 注册表快照与测试前一致，测试防护规则和 53 监听清理完成。
- 面向公网 IPv4、IPv6、虚拟网关和局域网网关的 TCP 53/853/5353/5355/137 在连接及断线阶段均返回 AccessDenied；UDP 发送调用成功须结合网卡证据，不能单凭此判定泄露或通过。
- 设置页已实际渲染检查，产品源码不再引用测试菜单或相关模块。

## 网卡出口证据

Windows Packet Monitor 的计数器能够观察到对照流量，但本机 ETL 转换出现格式错误，不能生成有效的逐包 PCAP；空 PCAP 不作为通过证据。

补充验收保留同一组端口筛选器，并执行“前置对照 → 计数清零 → 正常连接探测 → 核心断线探测 → 后置对照”：

| 阶段 | WLAN 上层出口 | FastLink 上层出口 | 解释 |
| --- | --- | --- | --- |
| 前置对照 | 1 包 / 81 字节 | 1 包 / 49 字节 | 非 DNS 对照数据发往 45453，证明监测可见 |
| 正常连接探测后 | 0 包 | 0 包 | 20 次 UDP 外发尝试、20 次 TCP 阻断、16 次 loopback 解析 |
| 核心断线探测后（累计） | 0 包 | 0 包 | 再做 20 次 UDP、20 次 TCP、16 次 loopback；loopback 均返回 SERVFAIL |
| 后置对照（累计） | 1 包 / 81 字节 | 1 包 / 49 字节 | 证明监测在结束前仍有效 |

筛选端口为 53、853、5353、5355、137 和对照端口 45453，监测范围为网络适配器；所有其他受监测组件在两个探测检查点也为零。因此，在当前共存环境及该测试窗口内，未观察到这些测试端口外发。证据为网卡计数与显式错误应答，并非完整逐包取证，不能据此扩展到任意 HTTPS DNS、未测应用或其他模式。

最终检查确认抓包停止、筛选器为空、测试 DNS 防护规则为零，FastLink/WLAN DNS 与基线一致。阶段数据见 `.build/acceptance/*-counters.json`、`capture-connected.json`、`capture-disconnected.json`、`counter-analysis.json`。
